# Telegram Spam Bot

## Описание

Этот проект представляет собой Telegram-бота, написанного на Python с использованием библиотеки Telethon, предназначенного для рассылки сообщений по списку контактов и чатов.  Он предоставляет функциональность управления через Telegram-бота, позволяя администратору запускать и останавливать рассылку, а также изменять текст сообщения. Бот также обрабатывает ошибки, связанные с ограничением на рассылку (FloodError, PeerFloodError) и предоставляет возможность автоматической остановки рассылки при получении сообщения от SpamBot.

**Внимание:** Использование данного бота для спама может привести к блокировке вашего аккаунта Telegram. Используйте этот инструмент ответственно и в соответствии с правилами Telegram.

## Возможности

*   **Управление через Telegram-бота:** Запуск, остановка и изменение текста рассылки.
*   **Рассылка по контактам:** Отправка сообщений всем контактам.
*   **Рассылка по чатам:** Отправка сообщений в группы, каналы и контактам (кроме ботов).
*   **Обработка ошибок:** Автоматическая обработка ошибок, связанных с ограничением на рассылку (FloodError, PeerFloodError).
*   **Автоматическая остановка при обнаружении спама:** Автоматическая остановка рассылки при получении сообщения от SpamBot.
*   **Уведомления:** Отправка уведомлений администратору через Telegram-бота о запуске, остановке и других событиях.

## Требования

*   Python 3.7 или выше
*   Библиотека Telethon: `pip install telethon`

## Установка

1.  **Клонируйте репозиторий (или скачайте ZIP-архив и распакуйте):**

    ```bash
    git clone <ссылка_на_репозиторий>
    cd <имя_директории_репозитория>
    ```

2.  **Установите необходимые библиотеки:**

    ```bash
    pip install telethon
    ```

## Настройка

1.  **Получите API ID и API Hash:**

    *   Перейдите на [https://my.telegram.org/apps](https://my.telegram.org/apps) и войдите в свою учетную запись Telegram.
    *   Создайте новое приложение и получите `API ID` и `API Hash`.

2.  **Получите токен Telegram-бота:**

    *   Найдите бота [@BotFather](https://t.me/BotFather) в Telegram.
    *   Следуйте инструкциям BotFather для создания нового бота и получения токена.

3.  **Найдите свой Telegram ID:**
    *  Используйте ботов типа [@userinfobot](https://t.me/userinfobot) для получения своего Telegram ID.

4.  **Отредактируйте файл `main.py`:**

    *   Замените значения переменных в верхней части файла `main.py` на свои:

        *   `API_ID` - Ваш API ID.
        *   `API_HASH` - Ваш API Hash.
        *   `SESSION_FILE` - Имя файла для хранения сессии (например, `'my_session.session'`).
        *   `PHONE` - Ваш номер телефона в международном формате (например, `'+79991234567'`).
        *   `BOT_TOKEN` - Токен вашего Telegram-бота.
        *   `MESSAGE` - Текст сообщения для отправки.
        *   `MAX_MESSAGES_PER_DAY` - Максимальное количество сообщений в день.
        *   `SLEEP_TIME_ON_FLOOD` - Время ожидания при FloodError (в секундах).
        *   `ADMIN_ID` - Ваш ID в Telegram.
        *   `SPAM_BOT_USERNAME` - Имя пользователя SpamBot.

## Запуск

1.  **Запустите файл `main.py`:**

    ```bash
    python main.py
    ```

2.  **Авторизуйтесь в Telegram:**

    *   При первом запуске вам будет предложено ввести свой номер телефона и код подтверждения, полученный в Telegram.

3.  **Управление ботом через Telegram:**

    *   Найдите своего бота в Telegram и начните с ним диалог.
    *   Используйте следующие команды:
        *   `/start` - Запуск бота.
        *   `/help` - Помощь.
        *   `/contacts` - Спам по контактам.
        *   `/chats` - Спам по чатам (каналам, группам) и контактам (кроме ботов).
        *   `/stop` - Остановить спам.
        *   `/settext <text>` - Установить текст для отправки.

## Описание переменных

*   **`API_ID`**: Уникальный идентификатор вашего приложения Telegram, полученный на [https://my.telegram.org/apps](https://my.telegram.org/apps).
*   **`API_HASH`**: Уникальный хэш вашего приложения Telegram, полученный на [https://my.telegram.org/apps](https://my.telegram.org/apps).
*   **`SESSION_FILE`**: Имя файла, в котором будет храниться информация о сессии Telegram.  Это позволяет боту автоматически авторизоваться при повторных запусках.
*   **`PHONE`**: Ваш номер телефона, используемый для авторизации в Telegram.  Должен быть указан в международном формате, например, `+79001234567`.
*   **`BOT_TOKEN`**: Токен вашего Telegram-бота, полученный от @BotFather.
*   **`MESSAGE`**: Текст сообщения, которое будет отправляться контактам и в чаты.
*   **`MAX_MESSAGES_PER_DAY`**: Максимальное количество сообщений, которое бот может отправить в течение одного дня.  Рекомендуется установить разумное значение, чтобы избежать блокировки аккаунта.
*   **`SLEEP_TIME_ON_FLOOD`**: Количество секунд, которое бот будет ждать при возникновении ошибки `PeerFloodError`.  Эта ошибка указывает на то, что вы отправляете слишком много сообщений слишком быстро.
*   **`ADMIN_ID`**: Ваш Telegram ID. Бот будет отправлять уведомления об ошибках и событиях на этот ID.
*   **`SPAM_BOT_USERNAME`**: Имя пользователя Telegram SpamBot. Бот будет отслеживать сообщения от этого бота и останавливать рассылку, если получит предупреждение о спаме.
